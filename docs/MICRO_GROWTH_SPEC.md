# V10.9 苹果屋窗灯

每个苹果屋世界实例独立判定。三位居民必须分别实际抵达、触发该实例当前苹果屋形态的互动。每位居民计一次，重复到访、规划路线、动画播放和时间经过均不会替代缺少的居民。第三位到访时，同一次存储提交写入正常互动及 `WINDOW_LIT`，事件 ID 为 `<objectInstanceId>/window-lit`，用于去重。

Scene 从真实成长事件推导已亮灯实例，并在苹果屋现有右侧窗户中心叠加三层暖色微光。这是独立 Phaser Graphics 层，保留原 Sprite、锚点、坐标、占地和实例身份。只绘制当前在岛上的苹果屋。布置簿的「显示窗灯」可以关闭该视觉，偏好可刷新恢复，成长及回忆仍存在。未到阈值的房屋会在刷新恢复时重新加入探索，已记录的居民仍去重。重大用途依旧必须确认。

## 验收

自动化覆盖两位居民后仍未亮灯、重复互动/仅发现不计入、刷新后第三位到访点亮、再次到访不重复事件、ID 与占地保持。布置簿自动化覆盖无效实例、独立页面和删除隔离。浏览器使用真实居民和苹果演变链路验证窗口微光及存储。文件范围为 Store、Bridge、场景独立覆盖层与缩略图渲染、React 布置簿、入口/版本、测试和文档。Living Sky renderer、图层、天气状态规则及紫色星空资产保持原样。

构建通过，V10 28/28、V7 6/6。Chromium 1210×834 CSS px、DPR 2 实测苹果两阶段演变、三位居民到访与窗灯点亮、窗灯偏好和两个快照刷新恢复、删除隔离、叶子船迁移、三模式与单 Canvas。实测截图及日志在工作区 `evidence/v10.9/`。iPad 真机待验。
