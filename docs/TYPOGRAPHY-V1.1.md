# Observer Typography System V1.1

## 字体角色

- `--font-display` 使用方正像素 16 承担页面标题、主要操作、模式名称、中文物件名称和居民气泡。正文、说明和文本输入使用同样基于方正像素 16 的 `--font-body`。
- `--font-meta` 使用方正像素 12 承担状态、时间、编号、时间轴元信息和筛选标签。数字与状态使用 1.25 行高、轻微字距和等宽数字设置。
- `--font-logo` 保留 Isle Terminal Pixel。档案栏中的斜体品牌字保留既有随包字体。
- 标题、按钮和元信息共用统一行高变量。中英文名称在同一基线上排印，英文名称以较小字号补充。过长的物件名和时间轴标题最多两行；完整物件名仍可在详情中阅读。居民气泡限制宽度并按实际文字换行。

## 加载与授权

项目现有的 `isle-terminal-pixel.ttf` 和 `observer-cn.otf` 继续随工程分发，沿用原有随包许可。方正像素 12/16 在开发机已安装，CSS 仅通过 `local()` 匹配实际字体全名和 PostScript 名。没有复制或转换这两份字体，也没有引入字体网络请求。

本机安装和字体元数据只用于确认字体身份。**正式 Web 嵌入和项目分发的授权待确认**。部署现有工程时，未安装方正字体的设备由 Isle Terminal Pixel 和 ObserverCN 承担界面显示，缺字继续交给系统的中文及通用字体。超出系统字库覆盖的字形仍受设备限制。

## 验收记录

在 Chromium、1210×834 CSS px、DPR 2 检查 Terminal、World、Collection 和 Memories，逐屏生成 2420×1668 前后对照。Chrome 的实际字形字体报告确认标题、按钮、物件名和气泡使用 FZXS16，状态、时间和数字键号使用 FZXS12，Logo 继续使用 Isle Terminal Pixel。模拟两份本机字体不可用后，验证随包字体和系统回退有效。中英混排长气泡在两套字体下均换行，无横向溢出。真机字体与长期可读性尚待验收。
