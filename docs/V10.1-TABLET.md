# Observer V10.1｜横屏平板交付

基线为 V10 导出提交 `e729ee2`。从本目录运行：

```sh
npm ci
npm run build
npm test
npm run preview
```

打开 [本地 Observer](http://127.0.0.1:4173/)。预览使用随工程提交的 `dist`，已安装依赖只在重新构建时需要。Node 最低版本 20。

## 构建与文件边界

- `src/observer-v10.jsx` 和 `src/native-components.jsx` 是当前 React 源码。修改涉及终端测量、动态框架高度、档案页布局，以及将投放完成反馈移出 React 状态更新函数。旧 `src/observer.jsx` 保留用于历史参考。
- `scripts/build.mjs` 由 esbuild 读取当前 React 入口，只生成 `dist/observer-v10.js` 及 `.js.map`。本轮提交了重新生成的两份产物。
- `dist/index.html`、`dist/native.css` 和 `dist/native-tokens.css` 是直接随 HTTP 发布的可编辑文件。V10.1 修改了 HTML 的 viewport 和 CSS 的尺寸、排布与天空样式。调色 token 保持原值。
- `dist/main.js`、`world.js`、`terrain.js`、`observer-store.js`、`observer-bridge.js` 都是由 HTML 直接加载的业务源码。仅 `main.js` 有渲染改动，地形、世界逻辑、Store 与 Bridge 的 SHA-256 继续与 V10 相符。Phaser 及美术资源沿用本地分发文件。导出校验清单 `EXPORT-FILES.sha256` 对应收到的 V10 快照。
- `package.json` / `package-lock.json` 仅提升工程版本至 10.1.0。React / React DOM 19.1.1、esbuild 0.25.8、scheduler 0.26.0 维持锁定。
- `tests/native-policy.cjs` 和 `tests/fixtures/game-baseline.json` 更新字节校验范围以允许场景渲染修订。四份未编辑的游戏核心文件仍由原始哈希保护，既有行为测试持续运行。

## 尺寸、构图和输入

最终目标为 2420×1668 物理像素，约 1.45:1。在 Chrome 模拟 1210×834 CSS px、DPR 2 下，终端由 **1210×677.06** 增至 **1210×834**，消除约 **157 CSS px** 的上下空白。UI 逻辑宽度 1662，逻辑高度约 1146，统一缩放约 0.728。SVG 外框的 viewBox 和原生面板使用实际逻辑高度。Boot 重新分配留白，Collection 将浏览标签和筛选按钮分两行，Memories 增加时间轴与相框的纵向空间。

外框和独立的 Phaser portal 共用扣除安全区后的一个尺寸。Canvas 逻辑分辨率保留 688×432，Phaser Scale FIT 居中，显示为 **1143.03×717.70 CSS px**，两轴均约 **1.661×**。地图、世界原点、摄影机逻辑视野和格坐标保持原样。真实触屏落点仍由 Phaser 换算。HTML 启用 `viewport-fit=cover`，CSS 使用四边 `env(safe-area-inset-*)`，移动端浏览器栏高度通过 `dvh` 纳入计算。

天空移到透明 Canvas 下方，用源图 512×288 进行居中 cover，按同一倍率缩放并裁切边缘。场景中的物件和放置预览以 `drawSize` 为外接盒，取两轴允许的较小倍率。脚点、视觉深度、占地与碰撞保持各自配置。居民沿用源图等比渲染。

四张正式参考图在工作区根目录。212 为 Memories，213 为 Terminal，214 为 World，215 为 Collection。对照检查了色彩、像素边框、辉光、字体、按钮间距、面板比例、图标和文字层级。本轮视觉改动限于 4:3 构图与操作间距，参考图作为验收输入，运行时依然使用原生组件和既有独立游戏资源。
