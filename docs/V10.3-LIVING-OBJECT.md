# V10.3 First Living Object

## 演示入口

在 Observer 目录运行 `npm run build` 和 `npm run preview`，打开 [Observer](http://127.0.0.1:4173/)。

1. 从启动页按 T，或在终端菜单选择模拟 Explorer 传输。一次投递现有苹果、叶子两张照片。批次完成后进入 Collection 的 Discovery Pocket。再次按 T 会跳过已接收的同一批照片。
2. 点击苹果照片，查看采集原图与 Sprite，选择放入岛屿。在 Story Land 触摸格 (22,13) 并确认投放。叶子继续留在口袋中。
3. 等居民沿可行走路径到达。右上出现用途提议，打开并确认后得到巨型苹果。再次等待居民到达并提出苹果屋用途，确认后得到苹果屋。若居民临时占住目标格，保留原形态和提议，稍后重试；永久冲突需释放占地。
4. 等居民走到苹果屋门边。按 3 进入 Memories，切换「真实事件」查看放置、发现、提议、确认、演变与门口互动。刷新后，按 1 回到岛屿。

## 数据与事件

- **已有。** Store 持久化收藏、世界和事件，Bridge 把 Phaser 变化映射为档案，World 原有占地、碰撞、最短路径、门口可达、失败回退及演变后探索继续使用。
- **接收。** T 使用固定本地资源。外部入口可通过 `isleObserverInput.receiveTransfer({captures:[...]})` 或 `isle:explorer-transfer` 事件提交同样的批次。每条记录包含稳定的 `captureId`、`displayName`、`type`、`originalPhoto`，可带 `importedSprite`、`userNote`。未提供 Sprite 的记录可收藏，有现成可用 Sprite 的记录可逐件登岛。仍兼容旧的单条 `objectId` 输入。批次范围内和刷新后的重复 captureId 都会跳过。
- **身份关系。** captureId → 收藏 objectId → 世界实例 collectionId（档案中的 objectId）。同一实例跨三态保留 ID、世界落点和来源。Discovery Pocket 按该收藏是否有在岛实例决定待登岛状态。
- **运行事件。** `OBJECT_IMPORTED`、`OBJECT_PLACED` 来自实际落格。居民开始前往时记录 `RESIDENT_INSPECTED`，实际到达时记录 `RESIDENT_INTERACTED` 并允许首次 `USE_PROPOSED`。用户显式确认且占地验证成功后，同一次 Store 提交写入 `USE_CONFIRMED` 及 `OBJECT_SCALED` / `OBJECT_TRANSFORMED`，更新世界、形态并清除已消费提议。失败不产生确认或演变记录。刷新恢复未处理提议；如果现有形态还没有互动记录，恢复时重新安排探索。
- **模拟范围。** 用途文案和演示照片来自本地资源，提议触发、路径、到达、交互和事件来自真实 Phaser 世界。设备连接、真实批次传输协议、照片长期存储容量、实体按键和真机触摸仍待联调。
