# V10.7 Living Sky Runtime

Story Land 的天气由现有 Phaser 场景渲染。World 的「天空」控件提供离线预览、确认、取消和恢复默认，旁边可切换 Normal / Island Overview。其他岛仍为静态预览，原三个主模式和旋钮保持原样。

## 状态与环境照片

Store 持有独立的 `weatherId`、`source`、`activeSince`、`transitionState` 及可选 `captureId`。旧存档默认星尘晴，应用前无时间戳。预览和渲染过渡仅留在运行时；持久化快照为确认后的目标状态。离开 World 或按 Escape 取消未确认预览，刷新恢复最后确认的天气。同一确认状态不会重复写记录。确认时将天气与 `WEATHER_APPLIED` 真实事件同次写入本地存储；存储失败可重试。

World 面板可选择本地环境照片（JPEG、PNG 或 WebP，最多 1 MiB）。照片进入 Collection 的 Photos，保留来源与 ID，没有普通登岛按钮。入口明确标注「模拟晚霞建议」，选择照片只启动晚霞预览，确认才改变天气并记录关联事件。该入口未调用 AI。正式识别可沿用环境来源、建议和人工确认结构。

## 图层、相机与安全边界

- Sky Base、天体、云分层替换，位于地形后。环境光与粒子在居民和物件上方，低于放置提示、路径调试和 DOM HUD；CRT 仍是独立层。
- Normal 保持 1× 实际游戏镜头，Overview 为 .82× 同中心广角，视图偏好刷新重置。坐标命中走 Phaser 相机的反变换，居民气泡按相机坐标定位。照明与粒子不会进入碰撞或地图存档。
- Sky Base 按终端内框做等比 cover。Canvas 内的天空和内框底层共享源图、中心和比例，延伸覆盖等比画布外侧空间；不拉伸地形或角色。天体与云适度视差，有 14 逻辑 px overscan；颗粒在屏幕空间平铺。
- 1350 ms 正弦过渡，两套画布图层和底图同时淡入淡出，粒子升降预设 650 ms。只保留最后一个待切换目标。旧画布节点与 DOM 底图在完成后释放，减弱动态偏好使用静帧和即时切换。

## 验收

在 1210×834 CSS px、DPR 2 运行三套天气 × 两机位，保留六张实际 Phaser 截图。浏览器实测取消、默认恢复、环境照片、真实回忆事件、模式及旋钮、刷新恢复、单 Canvas。九次切换约 60 rAF/s（本机 Chromium）；天气节点峰值 10，结束为 5。场景节点前后均 17，天空 DOM 底图前后均 1。手动 GC 后 JS heap 约 11.48 → 11.78 MB；单次短测没有估算 GPU 内存或长期上限。
