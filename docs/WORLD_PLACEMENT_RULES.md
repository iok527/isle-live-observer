# Story Land 放置规则

审查基线为 V10.3 `9521b12`。本轮给同一校验函数增加诊断类别和格坐标，并将结果用于 Art Calibration。地图数据、占地、寻路算法和苹果演变规则继续沿用基线。

## 为什么空地很多，却只有一部分能放

`dist/assets/terrain-map.json` 初始 405 格包括 **86 格可走且允许放置、276 格只可走、43 格水域**。86 个候选地面格由 49 格铺装、29 格薰衣草和 8 格苔地组成。东扩 87 格中 27 格允许放置。颜色和地表纹理无法单独推断可放置性。天空背景、岸壁画出来的侧立面及岛外空白都可能没有地图格。

`dist/terrain.js` 负责按格和边界绘制。实际规则在 `dist/world.js` 的 `canWalk`、`blocked`、`checkPlacement`。可走要求基础 `walkable=true` 且当前没有实心物件覆盖。落点要求整组 footprint 命中允许放置的格，或符合物件的水域规则。配置里的水域以 `material:'water'` 表示，当前水格基础上不可走。World 从当前实心物件推导动态阻挡。地图里的 `fixedHouse` 和 V7 `fixtures.json` 当前未被 V10.3 场景注册为设施或碰撞体。

## 点某一格，为什么被拒绝

坐标为 16 px 世界格。调试给出当前物件在该格首先触发的限制，多个限制可同时存在。

- **岛屿边界外 `outside`**。锚格在 `world.cells` 外。空岛在 (0,0) 放苹果即可复现。
- **地形不允许 `terrain`**。锚格存在，但出于地面许可或水域类型而不合法。例如苹果在 (7,10) 命中水。
- **占地不足 `footprint`**。锚格可作入口，其他覆盖格超出边界或未开放放置。苹果屋锚格 (18,11) 时，左侧 (17,11) 首先失败。
- **已占用 `occupied`**。候选覆盖格与任意现存物件重叠，漂浮物同样占位。校准场的 (19,12) 已被苹果占用。
- **居民经过 `resident`**。候选覆盖格命中居民本格或下一步，反馈会提示稍后再试。
- **路径受阻 `route`**。假设放置后，从第一位居民的下一格或当前格做 BFS；其他居民的起点须都可达。另用 `after.size + footprint.length < before.size` 检查可走连通块是否明显缩水。
- **入口受阻 `entrance`**。候选须至少有一个落在该连通块的互动格。苹果屋正中心门格也必须可达，同时保留已有物件的至少一个互动格和已有苹果屋正门。例如湖心水格 (7,11) 对叶子没有可达岸点。已有物件冲突会报告物件及其锚格。
- **可放置 `valid`**。当前类型的整套规则通过。由于居民实时移动，下次确认仍以即时校验为准。

普通苹果、椅子、石头、猫用单格地面占地。巨型苹果往右追加一格；苹果屋覆盖锚格周围的 3×2 组，门指向南侧。叶子可用地面规则，也可在占地全为水格且岸边互动可达时漂浮。漂浮物加入占用检查，居民通行仍由地形决定。叶子船和石头休憩点仅在校准页注册。苹果演变使用相同锚格，调用 `checkPlacement(at, nextType, currentObject)`，排除自身旧占地，再应用同一套限制。

## 哪些规则值得调整

- **保留。** 地图边界、完整 footprint、对象重叠、居民当前格与下一步保护，以及至少一个可达互动点。苹果屋正门与居民互相可达也应保留。
- **调整候选。** 初始地面许可是主要限制。先按图逐格开放一小片宽前庭，在入口和窄道保留只走不放。地块扩张仍用原有规则。避免用材质或 `walkable` 自动扩大全图。
- **连通性审计。** 面积比较只是启发式。它用总 footprint 作为抵扣，可能漏掉小片断连，也可能把不含居民或互动点的死角切割判得过严；演变前基准排除了旧物件，可能比较到当前本来不通的连通面积。后续宜保护明确的出生区、连桥、固定入口及世界实例互动点，再决定是否保护普通地面面积。
- **数据没有把可走和可放混用。** 现有 Debug 的 `masks().placeable` 是基础地面许可减占用，省略了具体物件、水域例外、居民和入口。易误读的是显示含义。现有 `drawGrid` 的黄色点只检查局部可走，也不代表从居民起点全图可达。

## 调试入口

在工程目录运行 `npm run dev`，打开 [Art Calibration](http://127.0.0.1:5173/art-calibration)。展开右上 **Art Calibration**，勾选「检查放置规则」，选择物件。色层显示每一格作为该物件锚点的结果，点格可读第一条限制。关掉检查后恢复普通居民/物件点击。已有 Sprite 与通行覆盖层可独立切换。

正式 World 中，进入放置后触摸无效格，现有 Placement HUD 也会显示同样的错误文字，并禁用确认。按坐标从一个格重新核对时，以点击当下的结果为准。
